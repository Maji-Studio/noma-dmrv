# Active plans

This directory is a work queue, not a history. Keep a plan here only while it
has substantial unimplemented work, still matches the current architecture, and
has an owner actively responsible for moving it forward.

Every active plan must begin with:

- **Owner** — a person or team accountable for the next decision or delivery.
- **Status** — proposed, approved, in progress, or blocked, including the
  concrete blocker when applicable.
- **Last reviewed** — an ISO date when the plan was checked against current
  code, tests, and architecture.

Update the status banner when implementation changes the remaining scope. Move
the plan to [`docs/archive/plans/`](../archive/plans/) when it is completed,
superseded, implemented, reduced to a handoff, or becomes a historical research
or audit snapshot. Preserve the record through a rename; do not delete it.
Unresolved product or design decisions belong in
[`docs/open-questions.md`](../open-questions.md), not in an archived plan.

There are currently no active dated plans.
