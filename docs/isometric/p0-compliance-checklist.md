> Scope: `biochar` + `biochar-storage-soil-environments` documentation set in this repo.
> Status values: `open`, `in_progress`, `done`, `blocked`.

| Checklist ID | Requirement area | Current state | Required implementation target | Acceptance criteria | Owner | Status |
|---|---|---|---|---|---|---|
| `P0-01` | Ineligible biomass >25% cap | No RP-level model | Add reporting-period feedstock eligibility ledger (eligible vs ineligible mass) and computed fraction | RP record stores totals and computed ineligible fraction; rule outcome is queryable for issuance decisions | TBD | in_progress |
| `P0-02` | Counterfactual validity lifecycle | Counterfactual inputs exist but no lifecycle model | Add counterfactual assessment entity with assessment date, evidence window, valid-to date, and reassessment trigger fields | Every credited feedstock in an RP links to a non-expired counterfactual assessment | TBD | open |
| `P0-03` | Method B enforcement guardrail | App-layer: 30-sample switch check (`validateReactorSamplingMethodFn`) + ≥1/10 cadence engine (`deriveSamplingRequirement`) + fail-closed removal-submission gates (every Method A run sampled, ≥3 replicates per sampled run — `evaluateDurabilitySubmissionGates`). **ADR 0016 (Phase 1, 2026-06-19):** sampling moved off `reactors` to `production_processes`; `reactors.sampling_method` and the migration-`0052` DB trigger were **dropped** (migration `0057`) — DEC is Method A everywhere, so the reactor-grain DB guardrail had nothing left to guard. The process-grain DB trigger (count a process's samples since `established_at`) is **deferred to ADR 0017** with the super-admin Method-B unlock. The ≥1/10 cadence stays at the fail-closed submission gate **by design** — a point-in-time readiness check, not a single-row invariant. | Process-grain DB trigger/function guardrail (ships with the ADR 0017 Method-B unlock) | App-layer 30-sample + cadence + replicate gates hold; process-grain DB trigger re-instated when Method B is unlockable (ADR 0017) | TBD | in_progress |
| `P0-04` | Leakage pressure calibration/test structure | Pressure timeseries exists, calibration structure missing | Add reactor/run monitoring QA tables for calibration/test events and standards | Each pressure-monitored period has auditable calibration/test entries with timestamps and evidence refs | TBD | open |
| `P0-05` | Loss accounting adjustments | Incident reports exist, no loss-adjustment ledger | Add mass-loss adjustment table linking incidents to affected run/delivery/application and batch deduction | Credited mass excludes logged losses; adjustment chain is auditable end-to-end | TBD | open |
| `P0-06` | 200-year durability evidence completeness | Inputs exist; removal submission now fail-closes on incomplete durability evidence (eligibility H/C_org<0.5 & O/C_org<0.2 on per-run mean, Method A sampling, ≥3 replicates) and resolves a conservative soil-temp estimate (max site temp, 7°C floor, >1°C subdivide advisory). DB-layer: migration `0053` adds a `BEFORE INSERT/UPDATE` trigger on `credit_batches` blocking a `200_year` batch from reaching `verified`/`issued` while any linked application lacks soil-temperature value + source, plus a back-door trigger on `credit_batch_applications` preventing an incomplete application from being linked into an already-`verified/issued` batch. Live measurement-samples submit wiring remains sandbox-gated (R1). | Issuance-time guardrail ensuring linked applications provide required temperature/source evidence for 200-year batches | `verified/issued` transition fails when linked 200-year application durability evidence is incomplete (verified, migration `0053`) | TBD | done |
